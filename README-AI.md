### 4.2 Перевести 101 строку рассказчика на `play_narrator`

В `game/script.rpy` строки выглядят так (отступ 4 пробела):

```renpy
    voice "voice/narrator/7de18f9e53aaf682.mp3"
    "Май 1859 года. Солнце уже клонится к закату, но всё ещё жжёт пыльную большую дорогу."
```

Нужно получить:

```renpy
    $ play_narrator("7de18f9e53aaf682")
    "Май 1859 года. Солнце уже клонится к закату, но всё ещё жжёт пыльную большую дорогу."
```

Скрипт (запускать из корня `medieval/`, он же проверит количество замен):

```bash
py -c "
import re, pathlib
p = pathlib.Path('game/script.rpy')
s = p.read_text(encoding='utf-8')
new, n = re.subn(r'(?m)^(\s*)voice \"voice/narrator/([0-9a-f]{16})\.mp3\"\s*\$',
                 r'\1\$ play_narrator(\"\2\")', s)
assert n == 101, n
p.write_text(new, encoding='utf-8')
print('replaced', n)
"
```

Важно: заменяем **только** строки `voice "voice/narrator/..."`. Остальные `voice "voice/<герой>/..."`
не трогаем вообще. Никакой другой текст в `script.rpy` не менять.


### 5.5 Шрифты

Нужна антиква с полной кириллицей, ощущение печатной книги 19 века (роман 1862, не буквально
готика: готику по-русски читать невозможно).

Основной вариант - Old Standard TT (SIL OFL, кириллица есть, бесплатно распространяется с игрой):

```
mkdir -p game/fonts
curl -L -o game/fonts/OldStandard-Regular.ttf https://github.com/google/fonts/raw/main/ofl/oldstandardtt/OldStandardTT-Regular.ttf
curl -L -o game/fonts/OldStandard-Bold.ttf    https://github.com/google/fonts/raw/main/ofl/oldstandardtt/OldStandardTT-Bold.ttf
curl -L -o game/fonts/OldStandard-Italic.ttf  https://github.com/google/fonts/raw/main/ofl/oldstandardtt/OldStandardTT-Italic.ttf
curl -L -o game/fonts/OFL.txt                 https://raw.githubusercontent.com/google/fonts/main/ofl/oldstandardtt/OFL.txt
```

Если GitHub недоступен: локальные `C:\Windows\Fonts\pala.ttf` (Palatino Linotype) или
`georgia.ttf` тоже с кириллицей, но их нельзя вкладывать в сборку по лицензии; тогда
указать имя системного шрифта без файла и обязательно проверить на чистой машине.

Кириллицу проверять обязательно: отрендерить строку `«Отцы и дети» - Ёё Йй Щщ Ъъ` и глазами
посмотреть на скриншоте, что нет квадратов и подмены на DejaVu.

## 7. Грабли (наступали, не повторять)

1. **`script.rpy` - чужой текст.** Любая правка слов = нарушение задания. Разрешены только
   строки `$ play_narrator(...)` вместо `voice "voice/narrator/..."`.
2. **Размеры GUI-ассетов** менять нельзя: `Frame` с фиксированными `Borders` порвёт картинку.
3. **9-slice края** должны быть однородными по цвету в пределах 6-8 px, иначе швы на рамках.
4. **Тайлы** (`parchment`, `wood`) обязаны стыковаться. Рисовать элементы с оборотами на ±512,
   иначе на краях экрана будет видна сетка.
5. **`persistent` в `default`**, не в `init` - иначе значение перезаписывается при каждом старте.
   В готовом `narrator.rpy` уже правильно.
6. **`voice()` внутри `play_narrator`** - это `renpy.voice`, а не оператор; строка перед
   репликой должна быть `$ play_narrator("hash")`, иначе линт ругнётся на неизвестный оператор.
7. **Bold/Italic**: без `config.font_replacement_map` жирный будет синтетическим "раздутием",
   на антикве это заметно сразу.
8. **Не трогать `repo/`** - там рабочий репозиторий с remote-ами и наш прошлый релиз.
9. **Git Bash и Windows-пути**: `shutdown /s /t 60` превращается в путь; для таких команд
   нужен `MSYS_NO_PATHCONV=1`. `renpy.exe` принимает пути в кавычках с прямыми слэшами.
10. **Первый запуск** создаёт `.rpyc` и `game/cache`; в архив `git archive` они не попадали,
    это нормально. В коммит их не добавлять (в `.gitignore` уже есть `/game/cache`, `/dist`).
11. **DPI 125%**: если снимать окно внешним скриптом, нужен `SetProcessDPIAware`, иначе
    координаты и кадр идут в логических пикселях и обрезаются.
12. **Кириллица в консоли** - cp1251, вывод Python с русским текстом читать осторожно,
    лучше выводить ASCII-маркеры.
